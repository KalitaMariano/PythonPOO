# 🐍 Python POO

Repositório dedicado aos meus estudos de **Programação Orientada a Objetos (POO) com Python**, acompanhando o curso **Python 3 – Mundo 4**, do Curso em Vídeo.

## 📚 Objetivo

Praticar os principais conceitos de orientação a objetos em Python por meio de exercícios e pequenos projetos.

## 🧠 Conteúdos

Durante os estudos, serão abordados:

* Classes e objetos
* Atributos e métodos
* Métodos especiais
* Encapsulamento
* Herança
* Abstração
* Polimorfismo
* Getters e Setters
* Properties
* Tratamento de exceções
* Projetos utilizando POO

## 📂 Organização

`exercicios/` — exercícios realizados durante as aulas.

`desafios/` — desafios e projetos desenvolvidos para praticar os conceitos aprendidos.
